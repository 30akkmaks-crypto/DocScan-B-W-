# 📄 DocScan B&W — сканируй документы в черно-белом режиме за секунду

> «Чёрно-белый — это не скучно, это элегантно и эффективно»

**DocScan B&W** — это набор консольных утилит для автоматического обнаружения границ документа на фотографии, коррекции перспективы и преобразования в черно-белый (бинарный) режим.  
Программа идеально подходит для оцифровки чеков, документов, книг и любых текстовых материалов, где важен контраст и читаемость.

## 🚀 Особенности
- 🧠 Автоматическое обнаружение четырёх углов документа.
- 🔄 Коррекция перспективы (гомография) — получается ровный прямоугольник.
- ⚫ Преобразование в черно-белый режим (адаптивная бинаризация).
- 🎛️ Настройка порога бинаризации (автоматический или ручной).
- 📷 Поддержка форматов: JPG, PNG, BMP, TIFF.
- 📁 Пакетная обработка (передайте папку — обработается всё).
- 📤 Экспорт в PNG, JPEG и PDF (где реализовано).
- 🎨 Цветной вывод в терминале и прогресс-бар.

## 🛠️ Установка и запуск

Для каждого языка — минимальные зависимости.

| Язык       | Библиотека(и)                          | Команда запуска                         |
|------------|----------------------------------------|-----------------------------------------|
| Python     | `opencv-python`, `Pillow`, `numpy`     | `python docscan.py image.jpg`           |
| Go         | `gocv`                                 | `go run docscan.go image.jpg`           |
| JavaScript | `opencv4nodejs` (или `jimp`)           | `node docscan.js image.jpg`             |
| Java       | `OpenCV (JavaCV)`                      | `javac -cp .:opencv.jar ... && java ...`|
| C#         | `OpenCVSharp`                          | `dotnet run image.jpg`                  |
| Rust       | `opencv-rs` или `image-rs`             | `cargo run -- image.jpg`                |
| Ruby       | `rmagick` + `opencv`                   | `ruby docscan.rb image.jpg`             |
| PHP        | `Imagick`                              | `php docscan.php image.jpg`             |
